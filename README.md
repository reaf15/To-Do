# 남양주체육문화센터 직원간 시설·공사 업무 공유 시스템

남양주체육문화센터 시설관리팀(김일호, 권병학, 조현호 및 담당 직원)의 시설보수, 수선유지, 공사 추진 현황을 실시간으로 관리하고 직원간 공유할 수 있는 스마트 업무 시스템입니다.

---

## 🌟 주요 기능 및 특징

1. **스마트 대시보드 (KPI 통계)**
   - 전체 추진 공사 건수 (**총 35건**)
   - 총 예상 소요예산 (**1억 9,300만원**)
   - 집행 예정금액 (계약금액 > 견적가 > 예상비용 우선순위 합산)
   - 진행 상태 및 완료율 실시간 시각화

2. **다양한 업무 뷰 모드**
   - 📊 **표 (스프레드시트 뷰)**: 엑셀과 동일한 표 구성, 정렬, 빠른 상태/담당자 변경, 업체 전화 걸기 및 복사
   - 📋 **칸반 보드 뷰 (Kanban)**: `접수/대기 ➔ 검토/협의 ➔ 견적의뢰/방문 ➔ 계약/공사진행 ➔ 완료` 파이프라인
   - 🏢 **시설별 보기**: 남양주센터(22건), 다산멀티(1건), 도농공원(2건), 삼패야구장(1건), 컨퍼런스(7건), 파크골프(2건) 구역별 현황
   - 👥 **담당자별 현황**: 김일호, 권병학, 조현호 및 미배정 건 부하 분석 및 업무 배정

3. **직원간 협업 & 업무 공유**
   - **접속자(페르소나) 변경**: 상단에서 '김일호', '권병학', '조현호' 선택 시 `내 담당 업무` 1클릭 조회
   - **업무 일지(타임라인 댓글)**: 현장 실측 내용, 일정 약속, 업체 전달사항 기록
   - **카카오톡/사내메신저 원클릭 공유**: 단톡방용 서식 텍스트 자동 생성 및 복사
   - **실제 엑셀(XLSX) 내보내기**: 원본 서식과 동일한 규격으로 Excel 파일 다운로드
   - **공문/결재용 인쇄 서식**: 결재란(담당/팀장/본부장)이 포함된 공식 보고서 출력 지원

4. **데이터 영속성 및 안전 복원**
   - 웹 브라우저 로컬 스토리지(LocalStorage)에 자동 저장
   - 원클릭 초기 데이터 복원(Reset) 기능 제공

---

## 🚀 실행 방법

### 방법 1. 간편 실행 (바탕화면 / 폴더)
- 폴더 내 `실행하기.bat` 파일을 더블클릭하면 브라우저가 자동으로 열립니다.

### 방법 2. 터미널 실행
```bash
npm install
npm run dev
```
접속 주소: **http://localhost:5173**
